# DSAVision

Interactive visualizers for data structures and algorithms. Step through animations, inspect code in multiple languages, and explore Big-O time and space complexity.

## Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- React Router

## Scripts

```bash
pnpm dev      # Start dev server
pnpm build    # Production build
pnpm lint     # ESLint
pnpm preview  # Preview production build
```

## Routes

| Path | Description |
|------|-------------|
| `/` | Algorithm catalog |
| `/binary-search` | Binary search visualizer |
| `/big-o-notation` | Big-O reference (time & space) |
